# 拾语使用与复现

更新：2026-10-30

本文说明公开仓库中的 PC 与 Android 应用如何安装、运行、存储数据和排查常见问题。实验数据、LoRA Adapter、MNN/GPTQ 产物、个人录音和真实聊天数据库不属于公开运行包。

## 1. 架构

```text
PC React UI
    -> FastAPI
    -> OpenCode Go / DeepSeek API
    -> SQLite 聊天、记忆、摘要与状态
    -> 可选 FTS5 + BGE 检索
    -> 可选 Whisper + GPT-SoVITS / MeloTTS

Android Compose UI
    -> OpenCode Go / DeepSeek API
    -> Room 聊天、记忆、摘要与状态
    -> FTS4 + 词法排序
    -> sherpa-onnx ASR + Kokoro TTS
    -> MediaPipe SD1.5 / 千问 Qwen-Image
```

PC 与 Android 是两套独立客户端。功能规则基本一致，数据不会自动同步。

## 2. PC 安装

### 2.1 前置条件

- Windows 10/11。
- Python 3.11。
- Git。
- Node.js 20+ 与 pnpm。
- 可选 NVIDIA GPU。主链路调用云端 API，显卡不是文字聊天的必需条件。

### 2.2 建立环境

```powershell
git clone https://github.com/bawdwl/shiyu-qwen3-chat.git
cd shiyu-qwen3-chat

conda create -n shiyu-chat python=3.11 pip -y
conda activate shiyu-chat
python -m pip install --upgrade pip
python -m pip install -r requirements-lock-windows-py311.txt
```

### 2.3 构建前端

```powershell
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
```

构建结果写入 `web/react-dist/`，FastAPI 从 `/ui/` 提供这些文件。

### 2.4 启动文字与图片聊天

```powershell
python launch_app.py --provider opencode --speech-provider off --asr-provider off
```

打开 <http://127.0.0.1:8000/ui/>。

在“应用设置”中填写自己的 OpenCode Go Key。也可以切换到 DeepSeek 并填写对应 Key。两个 Key 分开保存，不返回浏览器。

### 2.5 可选 BGE 语义记忆

```powershell
python scripts/fetch_embedding_model.py
```

模型下载到 `outputs/models/bge-small-zh-v1.5/`。BGE 缺失或失败时自动使用 FTS5 和词法检索，不影响基本聊天。

### 2.6 可选 PC 语音

PC 语音依赖本地 Whisper、MeloTTS 或 GPT-SoVITS 模型。相关模型和参考音频不随仓库发布，具体配置见 [语音部署](语音部署.md)。

## 3. Android 安装

### 3.1 直接安装

下载 [shiyu-android-0.9.4.apk](../release/shiyu-android-0.9.4.apk)。

```text
版本：0.9.4
versionCode：14
Room schema：10
SHA-256：EB05102FECF867446F6EF99472E816E9154046DF678C995F0D3A3C387D5B95D7
```

安装后：

1. 打开“应用设置”。
2. 选择 OpenCode Go 或 DeepSeek。
3. 输入自己的 API Key。
4. 返回角色首页创建或打开角色。
5. 需要语音时允许麦克风权限。
6. 需要本地头像时单独下载并导入 MediaPipe SD1.5 模型。

### 3.2 源码构建

需要 JDK 17、Android SDK 35。

```powershell
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\Users\<you>\AppData\Local\Android\Sdk"
.\scripts\build_android.ps1
```

或使用 Android Studio 打开 `android/`。

构建产物：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Android 本地语音 AAR、ASR 和 Kokoro 模型由 Git LFS 管理。首次克隆后如未自动拉取：

```powershell
git lfs install
git lfs pull
```

## 4. Android 本地头像

MediaPipe SD1.5 模型约 1.78 GiB，不包含在 APK 和普通 Git 对象中。

```powershell
python scripts/fetch_mediapipe_sd15.py
```

将 `outputs/models/mediapipe-sd15/sd15-mediapipe.zip` 传到手机，在拾语“应用设置”中导入。

角色编辑页有“外貌描述”。首次本地生图时，聊天模型会将中文资料整理为 SD 所需的内部视觉提示并缓存；后续生成可复用。云端 Qwen-Image 直接使用中文资料，需要单独的千问图片 API Key。

## 5. 建议验收流程

建议按以下顺序验收：

1. 启动 PC，填写 Provider Key。
2. 创建一个角色，检查姓名、背景、性格、世界书和知识边界。
3. 发一条普通消息，确认流式显示和停止按钮。
4. 明确告诉角色一个事实，继续聊几轮，再追问该事实。
5. 更正该事实，再问“现在”和“以前”两个版本。
6. 删除一条长期记忆，再次追问，确认没有复活。
7. 上传一张图片，询问图片可见内容。
8. 创建第二个角色，确认两个角色记忆隔离。
9. 在 Android 安装 APK，填写 Key 后重复核心流程。
10. 测试麦克风识别、停止播放、角色删除和房间数据库升级。

## 7. 数据、密钥与发布边界

不进入 Git：

- API Key、Secret Store 主密钥和 `.env`。
- SQLite/Room 聊天数据库。
- 个人录音、语音参考和生成音频。
- Qwen、LoRA、MNN、GPTQ、BGE、Whisper、MeloTTS 等大模型权重。
- MediaPipe SD1.5 模型。
- 用户上传图片和角色生成图片。
- LoRA 训练数据、实验输出和本地工具链。

PC API Key 默认保存在 Git 忽略的 `outputs/`。Android Key 使用 Android Keystore/EncryptedSharedPreferences。

## 8. 常见问题

### 填入 Key 后仍提示 401

先在 Provider 控制台确认 Key 有效、额度可用、模型有权限。不要在 Issue 中粘贴真实 Key。

### PC 启动失败

查看终端和 `outputs/app-service.log`，确认目录可写、端口 8000 未占用、依赖安装完整。

### BGE 不可用

应用会回退到 FTS5/词法检索。可重新运行 `python scripts/fetch_embedding_model.py`。

### Android 语音没有声音

确认首次请求时 LFS 语音资产已拉取、已允许麦克风权限，并在角色菜单选择音色。语音模型仅保存在应用私有目录，不会上传云端。

### Android 生图失败

本地生图需要先导入 MediaPipe SD1.5；云端生图需要千问 Key。单次失败不会删除角色或聊天。

### 两台设备为什么不同步

当前没有账号或中心数据库。PC 与 Android 均在本机保存数据，跨设备同步属于后续工作。
