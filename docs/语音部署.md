# Windows 语音部署（GPT-SoVITS + Whisper）

这份说明是根据开发机已经运行过的配置整理的步骤，**尚未在全新电脑从头验证**。如遇安装失败，请先看末尾的排错信息。语音和聊天使用不同的 Python 环境；GPT-SoVITS 在 CPU 运行，不占用聊天模型的显存。

## 1. 完成文字聊天安装

先按照 [README](../README.md) 安装拾语、下载 Qwen3 模型并确认文字聊天正常。后续命令除特别注明外都在拾语项目根目录执行。

## 2. 安装 GPT-SoVITS

安装 [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)（命令为 `pwsh`），并按[官方安装说明](https://github.com/RVC-Boss/GPT-SoVITS/tree/b4570b876f5c086819ba84e3215472733c6a7b70#installation)准备 Git、Conda 和网络。打开 Anaconda Prompt：

```powershell
mkdir third_party
git clone https://github.com/RVC-Boss/GPT-SoVITS.git third_party/GPT-SoVITS
cd third_party/GPT-SoVITS
git checkout b4570b876f5c086819ba84e3215472733c6a7b70
conda create -n shiyu-tts python=3.10 pip -y
conda activate shiyu-tts
pwsh -File install.ps1 --Device CPU --Source HF
```

这是官方安装路径，可能下载数 GB 的权重；安装所需许可与依赖由上游提供。开发机安装时曾遇到 Conda 插件、网络和 Windows C++ 编译问题，后来使用依赖兼容处理才成功，因此上述官方命令尚不能保证在所有电脑上一遍通过。安装完成后确认以下文件存在（名称与本项目测试的 v2 模型一致）：

```text
GPT_SoVITS/pretrained_models/chinese-roberta-wwm-ext-large/
GPT_SoVITS/pretrained_models/chinese-hubert-base/
GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s1bert25hz-5kh-longer-epoch=12-step=369668.ckpt
GPT_SoVITS/pretrained_models/gsv-v2final-pretrained/s2G2333k.pth
```

如文件缺失，按[官方预训练模型说明](https://github.com/RVC-Boss/GPT-SoVITS/tree/b4570b876f5c086819ba84e3215472733c6a7b70#pretrained-models)下载并放入对应目录，不要用其他版本的文件冒充。中文依赖和 FFmpeg 也按上游说明安装。

## 3. 启动 GPT-SoVITS 服务

在仍位于 `third_party/GPT-SoVITS` 的终端执行：

```powershell
python api_v2.py -c ../../docs/gpt-sovits-cpu.yaml -a 127.0.0.1 -p 9881
```

首次加载需要等待。浏览器打开 http://127.0.0.1:9881/docs 检查 API 页面；保持该终端运行。该地址仅本机使用。配置文件为开发机使用的 v2 CPU 配置，模型路径相对于 GPT-SoVITS 目录。

## 4. 启动拾语并配置音色

新开一个 Anaconda Prompt，进入拾语项目根目录：

```powershell
conda activate shiyu-chat
python launch_app.py --model-profile qwen3-1.7b --speech-provider gpt-sovits --tts-url http://127.0.0.1:9881 --asr-provider off
```

已有 GPT-SoVITS 服务时，启动器会连接它。打开 http://127.0.0.1:8000/ui/，选择角色，在设置中点击“配置当前角色音色”，上传本人录制或已获授权的 **3–10 秒 PCM WAV**，填写与录音逐字一致的文字并保存。随后聊天，回答完成后点击播放。不同角色需分别配置参考音频；上面的纯 GPT-SoVITS 模式不会自动为未配置的角色生成参考音色。

项目采用参考音频进行推理，不代表为每个角色训练了语音权重。开发者的录音和音色档案不会随仓库提供。

## 5. 可选：语音输入和回退声音

在 `shiyu-chat` 环境、项目根目录中执行：

```powershell
python -m pip install --target outputs/onnx-tts-runtime sherpa-onnx==1.13.8
python -m pip install --target outputs/media-runtime imageio-ffmpeg==0.6.0
python src/fetch_asr_model.py
python src/fetch_tts_model.py
```

关闭旧的拾语进程后，启动：

```powershell
python launch_app.py --model-profile qwen3-1.7b --speech-provider profiles --tts-url http://127.0.0.1:9881 --asr-provider whisper
```

`profiles` 模式为有参考音色的角色使用 GPT-SoVITS，其余角色使用 MeloTTS；Whisper 将录完的音频转成文字，不是实时识别。上述依赖和下载步骤尚未从空环境验证。

## 排错

- `GPT-SoVITS` 无法安装：检查网络、PowerShell 7、Conda、FFmpeg 和官方安装日志。开发机曾需要额外处理依赖和 C++ 扩展，不等同于上游一键安装已经通过。
- GPT-SoVITS 接口无法启动：在 GPT-SoVITS 目录运行命令，核对四项模型文件和配置文件路径；确认 9881 未被其他服务占用。
- 拾语提示音色未配置：进入该角色的音色设置，检查 WAV 与逐字稿都已保存。
- 听起来慢或不清楚：CPU 合成需要等待；参考音频应安静、清楚且内容与逐字稿一致。先用短句测试。
- 录音识别不准确：尝试安静环境和清晰录音；开发机上网页录音识别曾不如提前录好的音频稳定。
