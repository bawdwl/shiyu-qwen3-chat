# 角色卡、世界书和同会话记忆

角色卡保存身份、性格、开场情境、示例对话和生成参数。创建角色时，本地模型可按关键词生成草稿；生成内容需要由使用者检查和编辑。世界书条目包含关键词、优先级和启用状态，系统会按当前对话选择相关条目加入提示。

开场情境只在新对话开始时使用，示例对话默认不注入，以减少模型重复开场。输入模型前会有条件地省略最近多次回答中的重复句子；聊天记录仍保留原文。这种处理不能保证避免全部重复。

当上下文接近应用预算时，系统可以从较早的对话中提取原文片段供后续参考。界面提供查看、编辑、手动刷新和恢复入口；每个片段指向原消息。模型可能遗漏关键信息、选择不合适的片段，或因单条历史过长而无法自动整理。摘要不是永久记忆，也不保证长对话完全一致。每个会话独立，新建会话从空的动态记忆开始。

提示预览用于理解角色设定、世界书和记忆如何组合。实际生成前自动整理可能使最终提示和之前的预览不同。不要把虚构的角色经历视作用户真实信息。
