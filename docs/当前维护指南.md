# 当前维护指南

更新：2026-10-30

本仓库当前发布的是 PC 与 Android 可运行产品，而不是训练实验归档。完整安装步骤以 [使用与复现](使用与复现.md) 为准。

## 主链路

- PC：`frontend/`（React + TypeScript + Vite）→ `src/backend.py`（FastAPI）→ OpenCode Go / DeepSeek / 本地 Qwen 兼容入口。
- Android：`android/`（Kotlin + Compose + Room）→ OpenCode Go / DeepSeek。
- PC 数据：SQLite；Android 数据：Room schema 10。
- PC 检索：FTS5 + 可选 BGE；Android 检索：FTS4 + 词法排序。
- 每个角色一个持续对话。创建或重置时空对话获得一次主动开场。
- 角色回复是一条自然消息，动作使用中文括号；不展示四段式内心或好感度。
- 自动记忆、内部状态、Token 限制、删除墓碑和后台任务属于当前主链路。

## 启动 PC

```powershell
conda create -n shiyu-chat python=3.11 pip -y
conda activate shiyu-chat
python -m pip install -r requirements-lock-windows-py311.txt
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
python launch_app.py --provider opencode --speech-provider off --asr-provider off
```

访问 <http://127.0.0.1:8000/ui/>，在设置页填入自己的 Key。

## 构建 Android

```powershell
git lfs pull
$env:JAVA_HOME = "C:\path\to\jdk-17"
$env:ANDROID_HOME = "C:\Users\<you>\AppData\Local\Android\Sdk"
.\scripts\build_android.ps1
```

当前源码版本为 `0.9.4 / versionCode 14`，输出位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 测试

```powershell
python -B scripts/check_project.py
node --test tests/frontend_state.test.cjs
pnpm --dir frontend build
```

Android：

```powershell
cd android
.\gradlew.bat testDebugUnitTest assembleDebug --no-daemon
```

## 数据与发布边界

不要提交：

- API Key、`.env`、Secret Store、签名文件。
- SQLite/Room 数据库、个人录音和用户图片。
- Qwen/LoRA/MNN/GPTQ/BGE/Whisper/MeloTTS/MediaPipe 模型权重。
- 训练数据、Adapter、实验输出和本机 Android 工具链。

Android APK、本地语音 AAR 和 ONNX 模型通过 Git LFS 管理。公开前仍应运行密钥扫描并确认第三方模型许可。

## 当前限制

- 缺全新留出集和独立盲评。
- Android 没有内置 BGE。
- PC/Android 摘要管理尚未完全对齐。
- 反思、成长、World Clock、长期目标、实时双向语音、Live2D、多用户和跨设备同步尚未实现。
